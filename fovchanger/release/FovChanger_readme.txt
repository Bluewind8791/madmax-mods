FovChanger 1.0.0 for Mad Max (Steam)

Changes the camera field of view. Sniper rifle zoom still works.
Port of the Cheat Engine table "Mad Max Field of View Changer" by Carl Alldis, as an .asi mod:
no Cheat Engine needed.

Requirements
- Ultimate ASI Loader (x64) installed as dinput8.dll in the game folder.
- Steam version of Mad Max. On another game version the mod stays inactive and writes
  "not supported" to fovchanger.log.

Install
- Vortex: add this archive and enable it.
- Manual: copy fovchanger.asi and fovchanger.ini into the game folder (next to MadMax.exe).

Keys (while the game window has focus)
- F1: turn the mod on/off.
- = (+) / - on the main keyboard row: field of view wider / narrower.

Settings (fovchanger.ini)
- Multiplier: field of view multiplier at game start (1.0 = game default, 0.5 - 2.0).
- Step: change per key press.
- ToggleKey, IncreaseKey, DecreaseKey: Windows virtual-key codes (0 = no key).
  For Numpad +/- use 107 and 109.
- Changes made with the keys are not saved. Restart the game after changing the file.

Uninstall
- Disable the mod in Vortex, or delete fovchanger.asi, fovchanger.ini and fovchanger.log.
