InfiniteAmmo 1.0.0 for Mad Max (Steam)

Ammo in your inventory never goes down while you have at least one round of that type.
Weapons still reload. With 0 rounds the game behaves normally.

Requirements
- Ultimate ASI Loader (x64) installed as dinput8.dll in the game folder.
- Steam version of Mad Max. On another game version the mod stays inactive and writes
  "not supported" to infiniteammo.log.

Install
- Vortex: add this archive and enable it.
- Manual: copy infiniteammo.asi and infiniteammo.ini into the game folder (next to MadMax.exe).

Settings (infiniteammo.ini)
- Shotgun, Sniper, Thunderpoon, Shivs: 1 = infinite, 0 = normal.
- Restart the game after changing the file.

Tested
- Shotgun and sniper rifle: tested.
- Thunderpoon and shivs: not tested yet.

Uninstall
- Disable the mod in Vortex, or delete infiniteammo.asi, infiniteammo.ini and infiniteammo.log.
