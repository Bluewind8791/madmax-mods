CleanupCrewAnywhere 1.0.0 for Mad Max (Steam)

The stronghold Cleanup Crew collects scrap from defeated enemy vehicles anywhere on the map,
not only inside the territory of the stronghold where it was built.

You still have to build the Cleanup Crew project in at least one stronghold (find its project part
in that territory, then build it). Without it the mod changes nothing.
All other stronghold projects work as normal.

Requirements
- Ultimate ASI Loader (x64) installed as dinput8.dll in the game folder.
- Steam version of Mad Max. On another game version the mod stays inactive and writes
  "not supported" to cleanupcrewanywhere.log.

Install
- Vortex: add this archive and enable it.
- Manual: copy cleanupcrewanywhere.asi into the game folder (next to MadMax.exe).

Tested
- Cleanup Crew built in Jeet's and Gutgash's strongholds only: scrap from vehicles destroyed in
  Pink Eye's territory is collected.

Uninstall
- Disable the mod in Vortex, or delete cleanupcrewanywhere.asi and cleanupcrewanywhere.log.
